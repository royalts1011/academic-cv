A tool designed to help researchers screen and analyse large volumes of academic papers efficiently.

<!--more-->

Starting a new research area requires getting up to speed quickly — typically by screening large numbers of papers against specific criteria and identifying the most relevant ones. ResearchRabbit streamlines this process.

Users can upload papers they want to analyse and define a custom search schema with criteria relevant to their review, such as main contribution, datasets used, year of publication, and more. The tool processes each paper using OCR and extracts the requested information via an LLM backend service, presenting the results as a structured visual overview per paper.

The project is currently in active development. Planned features include export to JSON and richer data visualisations. The tool is also being evaluated for broader use cases such as PDF screening for funding acquisition and similar document-heavy workflows.
